# AI 顾问复杂账户诊断输出

## 文档定位

本文档说明复杂账户任务如何形成诊断判断，并生成 `summary` 和 `conclusion`。

- 复杂任务判定见 [`AI 顾问账户路由.md`](./AI%20顾问账户路由.md)；
- 最终结果结构见 [`AI顾问结果输出与组件编排.md`](./AI顾问结果输出与组件编排.md)；
- MCP 与卡片定义见 [`AI顾问账户卡片与数据.md`](./AI顾问账户卡片与数据.md)。

## 诊断理念

参考 Morningstar X-Ray，账户诊断的核心不是逐只介绍产品，而是说明：**这些产品组合在一起意味着什么，主要暴露和收益来源在哪里。**

当前项目没有 KYC、客户目标、风险舒适区和完整底层证券数据，因此只能诊断账户本身，不能判断账户是否适合用户，也不能直接进入配置或调仓建议。

```text
先看清账户
→ 再识别结构和表现问题
→ 最后定位原因
→ 诊断止于问题判断，不越界到组合优化
```

## 核心逻辑

```text
确定账户范围
→ 从单品清单转换为组合结构
→ 评价收益质量
→ 定位收益来源
→ 识别结构与收益之间的关系
→ 确定最值得关注的问题
```

### 1. 确定账户范围

先明确诊断覆盖全账户、分账户还是指定产品，以及对应的数据日期和诊断周期。

只取得部分账户数据时，只能评价该范围，不能代表用户全部资产。

### 2. 从单品清单转换为组合结构

依次回答：

```text
持有哪些产品
→ 资金是否集中在少数产品
→ 资产、地区和行业主要暴露在哪里
```

产品数量多不等于真正分散。当前 MCP 可以观察产品、资产、地区和行业结构，但不能推断晨星 X-Ray 所具备的完整底层证券重复持仓、相关性、费率和产品质量。

没有正式阈值时，只描述“主要集中于什么”，不判断“配置不合理”或“过度集中”。

### 3. 评价收益质量

账户表现不能只看赚没赚钱，要同时看：

```text
绝对收益：账户自身赚了还是亏了
相对收益：相对基准跑赢还是跑输
最大回撤：取得收益的过程中经历了什么波动
```

| 收益 | 超额收益 | 诊断表达 |
| --- | --- | --- |
| 正 | 正 | 账户赚钱且跑赢基准 |
| 正 | 负 | 账户赚钱，但表现弱于基准 |
| 负 | 正 | 账户亏损，但相对基准更抗跌 |
| 负 | 负 | 账户亏损且跑输基准 |

没有正式阈值或可比标准时，只报告最大回撤，不判断回撤是否过大。

### 4. 定位收益来源

收益归因回答：

- 主要收益由谁贡献；
- 主要亏损由谁拖累；
- 收益或亏损是否集中在少数产品、类型或行业。

归因只解释本次查询周期，不能解释其他时期的表现。

### 5. 识别结构与收益的关系

这是从“取数”进入“诊断”的关键一步：

| 结构事实 | 归因事实 | 诊断判断 |
| --- | --- | --- |
| 头部持仓 | 同一产品是主要拖累 | 主要拖累与头部持仓重合，应优先关注 |
| 头部持仓 | 同一产品是主要贡献 | 收益较依赖头部持仓，贡献来源较集中 |
| 主要行业或地区暴露 | 同一维度是主要拖累 | 结构暴露与本期拖累方向一致 |
| 主要行业或地区暴露 | 同一维度是主要贡献 | 本期收益较依赖该结构暴露 |
| 结构集中 | 没有对应负归因 | 只能认定结构集中，不能认定它已造成问题 |

只有产品标识、账户范围和周期一致时才能建立关系；否则只能并列陈述事实。

### 6. 确定问题优先级

```text
第一优先：已经造成主要拖累，且与头部持仓或主要暴露重合
第二优先：账户跑输基准或发生回撤，但原因尚未完全定位
第三优先：收益依赖少数产品或单一暴露，但当前尚未形成拖累
第四优先：只有结构特征，尚未发现对收益的实际影响
```

最终只保留最重要的一至三个发现。

## 输出逻辑

复杂诊断任务只生成 `summary` 和 `conclusion` 文案。业务 Section、卡片、顺序、固定字段和卡片参数由代码按上游计划拼接。

```text
summary
→ 代码拼接的业务 Section 和卡片
→ conclusion
```

### Summary

回答“账户当前最重要的诊断结果是什么”：

```text
账户范围和周期
+ 收益质量或结构的整体特征
+ 第一优先级问题及核心证据
```

### Conclusion

回答“这些持仓组合在一起意味着什么”：

```text
结构、表现和归因的综合判断
+ 问题优先级
+ 当前数据不能支持的判断
```

`conclusion` 不重复数字清单、不引入新事实，也不输出没有依据的买卖或调仓建议。

## 示例

用户问：“我的账户怎么样？”

```text
已校验事实：
账户收益率 -2.8%，超额收益 -3.8%；
产品 A 是第一大持仓；
同一周期内，产品 A 也是第一大拖累。

诊断：
账户亏损且跑输基准；主要拖累与头部持仓重合，当前结构放大了产品 A 对账户的影响。

summary：本次诊断显示，账户在该周期亏损 2.8%，并跑输基准 3.8 个百分点。第一大持仓产品 A 同时是第一大拖累，是当前最需要关注的因素。

conclusion：综合来看，账户本期表现偏弱，且主要拖累与头部持仓重合，产品 A 对账户损益的影响优先级最高。由于缺少用户目标和风险承受能力数据，本次不判断该持仓是否适合用户，也不形成调仓建议。
```

## 数据边界

- 部分数据可用：只形成有证据的局部诊断，并说明缺失维度；
- 核心数据不可用：明确不能形成账户级判断；
- deferred 卡片仍可输出，但不能用卡片未来可能加载的数据补写诊断；
- 诊断结果只说明账户现状、表现和来源，不替代 KYC、资产配置或组合优化。
