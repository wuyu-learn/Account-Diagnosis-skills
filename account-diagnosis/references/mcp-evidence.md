# MCP Evidence

## 职责

为 Summary 或复杂诊断取得最少且足够的真实证据。卡片计划与 MCP 计划相互独立：卡片决定前端展示，MCP 只支持文字回答。

## 可用工具

| 工具 | 能力 |
| --- | --- |
| `queryAssetsTotal` | 总资产和账户构成 |
| `queryAssetIndex` | 今日账户表现 |
| `queryAssetClassify` | 基金类型、资产、地区和行业分布 |
| `queryHoldingDetail` | 持仓明细和基金穿透 |
| `queryHoldingSignal` | 今日持仓提醒 |
| `queryShareDetail` | 指定产品份额 |
| `queryProfitAnalyze` | 区间收益、基准比较和回撤 |
| `queryProfitAnalyzeSum` | 收益总览 |
| `queryProfitAttribution` | 产品、类型或行业收益归因 |
| `queryProfitCalendar` | 日、月或年收益日历 |

参数、Schema、鉴权和错误结构以运行时 MCP 定义为准，不根据本文猜测。

## 规划

```text
读取 originalQuery 和账户计划
→ 明确文字任务必须回答的问题
→ 选择最少必要 MCP
→ 使用可信运行时上下文构造参数
→ 调用并校验返回结果
→ 只保留可用于本次回答的证据
```

禁止按卡片逐张调用 MCP。选中卡片不代表必须调用业务相近的工具。

## 数据质量

每个结果必须区分：

```text
available   数据完整且口径可用
partial     部分数据可用
unavailable 调用失败、空数据、缺少上下文或无法校验
```

检查：

- 真实零值、空数据和不可用；
- 实际数据和估算数据；
- 用户、账户和产品范围；
- 收益、基准、回撤和归因周期；
- 跨 MCP 关联使用的可信产品标识；
- 金额、比例、日期和正负号口径。

对象、账户范围或周期不一致的数据不能强行建立关系。

## 复杂诊断交接

只有 MCP 结果完成上述检查后，才能交给复杂诊断任务。交接内容包括：

- 上游原样透传的 `originalQuery`；
- 只读的账户计划；
- 每项证据对应的 MCP 来源、可用状态、账户范围、数据日期或周期、可信对象标识和已校验事实；
- 空数据、部分可用、估算值、口径冲突和无法关联的明确标记。

不把 MCP 原始响应直接当作诊断结论。存在范围、周期或对象冲突的证据保持分离，由复杂任务明确说明不能建立关系。

## 边界

- MCP 数据不写入 `cards[].data`；
- 不向外输出 MCP 计划、原始请求、原始响应或身份信息；
- `custNo`、`accountName`、会话和鉴权只来自可信运行时；
- 缺少可信上下文时不得猜测；
- 不得使用 deferred 卡片未来可能加载的数据补写文字；
- 单个 MCP 失败不删除已选卡片。
