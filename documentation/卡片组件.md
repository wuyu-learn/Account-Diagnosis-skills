# 账户诊断组件卡片清单

> Agent 速查用：汇总全部卡片组件。

| 卡片字段 | 编号 | 卡片名称 | 用户触发场景 |
|---|---|---|---|
| `acc01-total-asset` | ACC-01 | 账户总资产 | 我有多少钱 / 账户总资产 / 我的钱构成 / 某个账户怎么样 |
| `acc02-fund-account` | ACC-02 | 基金账户详情 | 我基金账户怎么样 / 基金账户赚了多少 / 基金账户里有哪些 |
| `acc03-fund-holding` | ACC-03 | 基金持有详情 | 我这只基金持有得怎么样 |
| `acc04-advisor-account` | ACC-04 | 投顾账户详情 | 我投顾账户整体怎么样 / 投顾账户里几个组合 / 投顾赚了多少 |
| `acc05-advisor-combo` | ACC-05 | 投顾组合详情 | 我的稳健回报组合怎么样 / 这个组合赚了多少 / 组合里买了啥 |
| `acc06-advisor-rebalance` | ACC-06 | 投顾调仓记录 | 我这组合都调过哪些仓 / 上次调仓干了啥 / 为什么调仓 |
| `acc07-money-account` | ACC-07 | 货币账户详情 | 我货币基金多少钱 / 现金宝收益 |
| `acc08-money-holding` | ACC-08 | 货币持有详情 | 点击触发 |
| `acc09-private-account` | ACC-09 | 专户账户详情 | 我专户产品怎么样 |
| `acc10-private-holding` | ACC-10 | 专户持有详情 | 点击触发 |
| `acc11-position-detail` | ACC-11 | 持仓明细 | 我都买了哪些 / 每只怎么样 / 看持仓 |
| `acc12-asset-structure` | ACC-12 | 资产结构 | 我的钱怎么分布 / 在各维度怎么分 / 是否集中 |
| `acc13-return-overview` | ACC-13 | 账户收益总览 | 我赚了多少 / 收益怎么样 / 跑赢大盘了吗 |
| `acc13-return-overview` | ACC-13-A | 滚动区间 |  |
| `acc13-return-overview` | ACC-13-B | 固定区间 |  |
| `acc14-return-calendar` | ACC-14 | 收益明细日历 | 我每天/每月/每年收益 / 哪段时间赚亏 |
| `acc15-return-attribution` | ACC-15 | 收益归因 | 我的钱为什么赚/亏 / 主要靠什么赚的 |
| `acc16-return-composition` | ACC-16 | 收益构成 | 我的收益从哪几块来的 / 哪类资产赚得多 |
| `acc17-period-attribution` | ACC-17 | 区间收益归因 | 这段时间我这只基金赚的是怎么来的 / 我买在什么位置 / 回撤多大 |
| `acc18-watchlist-valuation` | ACC-18 | 自选基金估值卡 | 我自选基金今天怎么样 / 看估值 / 净值更新了吗 / 我关注的基金涨跌 |
