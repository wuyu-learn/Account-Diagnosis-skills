# 晨星投顾理念与 X-Ray 账户诊断

## 1. 文档定位

本文从《晨星账户诊断资料归纳》中抽取两部分内容：

1. 晨星投顾全流程所体现的服务理念；
2. 与当前账户诊断项目直接相关的 Morningstar X-Ray。

本文用于明确理念、业务位置和能力边界，不展开技术实现方案。

## 2. 晨星投顾全流程

晨星将投顾描述为一套以客户为中心的连续服务：

```text
KYC 与风险画像
→ 目标规划
→ X-Ray / KYP 账户诊断
→ 资产配置
→ 组合构建与优化
→ 定期报告与投后追踪
```

| 环节 | 核心问题 |
| --- | --- |
| KYC 与风险画像 | 客户是谁，能够并愿意承担多少风险 |
| 目标规划 | 客户为什么投资，需要多少钱，什么时候使用 |
| 账户诊断 | 当前持有什么，承担什么风险，是否与客户匹配 |
| 资产配置 | 为实现目标，合理的资产结构是什么 |
| 组合构建 | 用哪些产品和权重落实资产配置 |
| 投后追踪 | 目标是否按计划推进，账户是否发生偏移 |

## 3. 全流程体现的投顾理念

### 3.1 以客户为起点

投顾不是从市场热点或产品销售开始，而是先理解：

- 投资目标；
- 投资期限；
- 资金用途和现金流；
- 风险容忍度；
- 已有资产和持仓。

产品和组合是实现客户目标的工具，不是流程起点。

### 3.2 同时理解客户与产品

```text
KYC：了解客户
KYP：了解产品和客户当前组合
```

只有把客户风险画像与账户真实风险放在一起，才能判断组合是否匹配。

### 3.3 将目标、风险和时间联动

风险不能脱离目标和期限单独评价：

- 短期目标需要限制高风险敞口；
- 长期目标可以更充分利用风险承受空间；
- 资金流和目标金额影响资产配置；
- 风险画像决定客户可以接受的风险范围。

### 3.4 先诊断，再优化

晨星流程先分析现有账户，再进入资产配置和组合优化：

```text
先看清当前账户
→ 再判断是否匹配
→ 然后讨论如何配置和优化
```

诊断负责发现问题；组合优化负责解决问题。两者相连，但不是同一个环节。

### 3.5 重视期望管理

投顾不仅提供收益结果，也通过目标达成概率、现实预测、风险解释和基准比较，帮助客户形成合理预期。

### 3.6 从一次性服务转为持续陪伴

晨星流程包含：

- 月度或季度健诊报告；
- 目标进度管理；
- 投后追踪；
- 配置偏移监测；
- 再平衡提醒；
- 持续的顾问沟通。

账户诊断既是首次服务入口，也可以成为持续投后服务的触点。

## 4. Morningstar X-Ray 的业务位置

X-Ray 位于 KYC/目标规划之后、资产配置和组合优化之前，承担账户诊断和 KYP 的主要职责。

```text
客户风险画像
        ↓
Morningstar X-Ray
        ↓
账户结构、真实风险、风险匹配和配置盲点
        ↓
资产配置与组合优化
```

X-Ray 主要回答：

1. 客户完整账户中实际持有什么？
2. 穿透基金后，真实资产和风险暴露是什么？
3. 组合整体风险是否匹配客户风险舒适区？
4. 账户是否存在集中、重复、偏科、相关性或费率等盲点？
5. 组合相对基准的业绩表现如何？

## 5. X-Ray 的核心价值

材料归纳出的四项价值是：

- 透视账户全貌，还原真实资产结构和风险来源；
- 使用专业数据形成清晰、可靠的展示；
- 识别集中度、风格、行业暴露和费率等关键盲点；
- 用可视化降低理解成本，辅助顾问与客户沟通。

其核心不是展示更多数据，而是把分散的基金持仓转换为统一的组合视角。

## 6. X-Ray 的分析链路

材料展示的产品链路为：

```text
1. 持仓数据归集
2. 基金 E 账户赋能
3. 账户风险匹配
4. 业绩与底层透视
5. 多终端灵活接入
```

从分析角度可以归纳为：

```text
归集完整账户
→ 穿透产品底层持仓
→ 计算组合整体风险
→ 匹配客户风险舒适区
→ 扫描组合盲点
→ 展示业绩和基准对比
→ 形成诊断报告
```

## 7. 持仓归集与账户范围

X-Ray 支持：

- 客户自主输入基金和份额；
- 上传 Excel 或持仓截图；
- 建立模拟组合；
- 通过基金 E 账户同步跨平台公募基金持仓；
- 对接银行或券商机构持仓数据库；
- 查看客户整体账户；
- 按不同持仓平台分别查看。

账户范围是诊断的前提。只取得某一平台持仓时，只能评价该平台账户，不能代表客户全部资产。

## 8. 底层穿透

X-Ray 不停留在基金名称和产品数量，而是基于产品底层持仓，自下而上计算：

- 大类资产；
- 国家和地区；
- 行业；
- 大中小盘；
- 价值、平衡和成长风格；
- 股票估值；
- 债券类型和风险特征；
- 前十大底层证券；
- 基金之间的历史相关性；
- 基金公司集中度。

底层穿透用于发现“表面分散、实际集中”：持有多只基金，不代表底层证券、行业、地区和风格已经分散。

## 9. 组合风险与客户风险匹配

MPRS 是 Morningstar Portfolio Risk Score，即晨星投资组合风险评分。

材料强调，组合风险不能通过以下方式简单得到：

- 取单只产品的最高风险；
- 将产品风险等级按权重线性相加；
- 用基金数量代表分散程度。

组合风险需要考虑：

- 资产类别；
- 地区和行业集中；
- 产品和底层持仓相关性；
- 特质风险；
- 多维风险因子；
- 跨资产分散效果。

风险诊断的核心比较是：

```text
组合风险评分 MPRS
vs.
客户风险舒适区
```

最终判断组合风险是低于、处于还是高于客户可接受范围。

## 10. X-Ray 诊断维度

| 维度 | 主要内容 |
| --- | --- |
| 综合风险 | MPRS、风险舒适区和风险匹配结论 |
| 资产配置 | 大类资产结构和集中情况 |
| 地区 | 国家/地区权重及与基准比较 |
| 行业 | 周期、敏感、防御行业以及超配/低配 |
| 风格 | 大中小盘、价值平衡成长、风格箱 |
| 估值 | 市盈率、市净率、市销率、市现率 |
| 底层持仓 | 前十大证券和真实集中度 |
| 产品相关性 | 基金历史收益相关性矩阵 |
| 债券结构 | 债券类型、信用和利率风险特征 |
| 费用 | 综合费率、显性费用和隐性费用 |
| 管理人 | 基金公司数量和资产集中度 |
| 业绩 | 组合与基准走势及多区间回报 |
| 产品质量 | 基金评级、风险和相关产品信息 |

## 11. X-Ray 输出

X-Ray 输出的核心不是一组孤立卡片，而是一份可以解释的账户诊断结果：

```text
账户综合概况
→ 风险匹配结论
→ 资产配置和底层暴露
→ 关键集中与配置盲点
→ 组合和基准业绩
→ 完整诊断报告
```

材料展示的交付方式包括：

- H5；
- 手机、Pad 和网页嵌入；
- A4 PDF 报告；
- API；
- 银行或券商 App；
- 理财顾问工作台。

## 12. 与当前项目的关系

当前项目中的 `account-diagnosis`，从业务位置上对应晨星全流程中的：

```text
X-Ray / KYP 账户诊断
```

两者共同关注的范围包括：

- 账户资产与持仓；
- 资产结构；
- 收益表现；
- 收益来源；
- 数据卡片和诊断结果展示。

Morningstar X-Ray 补充了当前项目尚未充分表达的账户诊断内涵：

```text
完整账户归集
+ 基金底层穿透
+ 组合整体风险
+ 客户风险舒适区匹配
+ 集中、相关性、风格、行业和费率盲点
```

从业务边界看：

| 能力 | 与账户诊断项目的关系 |
| --- | --- |
| KYC 和风险画像 | 账户诊断的可信上游输入 |
| 目标规划 | 上游或相邻能力，不属于账户取数本身 |
| X-Ray / KYP | 与当前账户诊断项目直接对应 |
| 资产配置 | 使用诊断结果的下游能力 |
| 组合优化和调仓 | 属于策略域及适当性流程 |
| 定期健诊报告 | 账户诊断的持续服务形态 |

## 13. 可以作为项目理念的表达

```text
以客户为中心，而不是以产品为中心；
先了解客户，再了解账户；
先穿透真实持仓，再评价组合风险；
先完成诊断，再进入配置和优化；
不仅回答当前结果，也持续跟踪目标和风险变化。
```

Morningstar X-Ray 对账户诊断的核心启发可以概括为：

> 账户诊断不是告诉客户持有什么，而是说明这些持仓组合在一起意味着什么、是否与客户匹配，以及风险真正来自哪里。

## 14. 信息边界

现有材料没有披露：

- MPRS 的完整公式、因子和权重；
- 风险测评到风险舒适区的映射算法；
- 各项诊断规则的阈值；
- 数据不足时的评分方法；
- 配置建议的生成机制；
- AI 在风险评分和适当性判断中的权限。

因此，本文只描述晨星材料能够确认的理念和能力边界，不推测其专有实现。
