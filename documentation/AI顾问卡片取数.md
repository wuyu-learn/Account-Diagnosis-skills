# AI 顾问卡片取数

## 文档定位

本文档归档账户卡片清单和当前无可用接口的卡片。卡片与接口的对应关系见 `documentation/AI顾问取数协议.md`；接口参数与返回字段见 `documentation/AI顾问数据接口.md`；卡片组件清单见 `documentation/卡片组件.md`。

当前账户域接口依据：

- 《投顾小程序AI顾问-34113-AI顾问-设计文档》
- 版本：V1.0
- 修订日期：2026-07-23
- 接口归属：资产中心

## 卡片清单

可取数卡片如下；卡片与接口的对应关系见 `documentation/AI顾问取数协议.md`，接口业务参数取值见 `documentation/AI顾问数据接口.md`。

| `cardId` | 卡片名称 | 用户意图 |
| --- | --- | --- |
| ACC-01 | 账户总资产 | 我有多少钱 / 账户总资产 / 我的钱构成 / 某个账户怎么样 |
| ACC-02 | 基金账户详情 | 我基金账户怎么样 / 基金账户赚了多少 / 基金账户里有哪些 |
| ACC-04 | 投顾账户详情 | 我投顾账户整体怎么样 / 投顾账户里几个组合 / 投顾赚了多少 |
| ACC-07 | 货币账户详情 | 我货币基金多少钱 / 现金宝收益 |
| ACC-09 | 专户账户详情 | 我专户产品怎么样 |
| ACC-11 | 持仓明细 | 我都买了哪些 / 每只怎么样 / 看持仓 |
| ACC-12 | 资产结构 | 我的钱怎么分布 / 在各维度怎么分 / 是否集中 |
| ACC-13-A | 账户收益总览 | 我赚了多少 / 收益怎么样 / 跑赢大盘了吗 |
| ACC-13-B | 账户收益总览 · 分年视角 | 我去年赚了多少 / 历年收益怎么看 |
| ACC-14 | 收益明细日历 | 我每天/每月/每年收益 / 哪段时间赚亏 |
| ACC-15 | 收益归因 | 我的钱为什么赚/亏 / 主要靠什么赚的 |
| ACC-19 | 产品份额明细 | 我某产品有多少份额 / 产品份额明细 / 某只产品持有份额 |

备注：

- 收益归因接口的原始候选包含 ACC-16、ACC-17，但当前卡片清单不含这两张卡，不得生成。
- `GET /v1/asset/agent/index`（账户管家）和 `GET /v1/asset/agent/holding-signal`（今日提醒）暂无对应卡片编号。

## 无已确认接口的卡片

| `cardId` | 卡片名称 | 说明 |
| --- | --- | --- |
| ACC-03 | 基金持有详情 | 账户中某只基金的持有情况 |
| ACC-05 | 投顾组合详情 | 指定投顾组合的整体、收益和组合持仓 |
| ACC-06 | 投顾调仓记录 | 指定投顾组合的调仓历史、内容和原因 |
| ACC-08 | 货币持有详情 | 单只货币基金的持有详情 |
| ACC-10 | 专户持有详情 | 单个专户产品的持有详情 |
| ACC-18 | 自选基金估值卡 | 自选基金当日估值、净值更新和涨跌 |

命中上述卡片时输出 `unsupported_card` 错误并停止，不得生成空 `data.request`。`/v1/asset/agent/holding-detail` 只能用于 ACC-11 全账户持仓明细，`/v1/asset/agent/share-detail` 只对应 ACC-19 产品份额明细，均不得替代上述卡片。
