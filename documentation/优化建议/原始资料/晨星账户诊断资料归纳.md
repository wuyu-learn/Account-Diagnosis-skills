# 晨星账户诊断资料归纳

## 1. 文档定位

本文只归纳项目内两份晨星材料中的有效信息，作为后续讨论账户诊断的事实底稿，不涉及当前项目方案、技术设计或晨星未公开的评分公式。

资料来源：

1. [《晨星中国投顾解决方案_账户诊断-汇添富基金》](./原始资料/晨星中国投顾解决方案_账户诊断-汇添富基金.pdf)，2026 年 2 月，共 28 页，重点参考第 5-16、19-24、26 页；
2. [《晨星中国产品及服务简介》](./原始资料/【汇添富基金】晨星中国产品及服务简介%202026.02.pdf)，2026 年 2 月，共 49 页，重点参考第 7-10、15、25-41 页。

两份材料的账户诊断部分存在较多重复，本文合并记录。

## 2. 晨星投顾全流程

晨星将账户诊断放在一套以客户为中心的投顾流程中：

```text
KYC 与风险画像
→ 目标规划
→ X-Ray / KYP 账户诊断
→ 资产配置
→ 组合构建与优化
→ 定期报告与投后追踪
```

| 环节 | 材料中的主要内容 |
| --- | --- |
| KYC 与风险画像 | 风险测评问卷、个人风险画像、已有投资信息收集 |
| 目标规划 | 投资目的、期限、资金流、目标达成概率 |
| 账户诊断 | 账户透视、组合风险评价、风险匹配、风格与行业分析 |
| 资产配置 | 目标资产配置、现实概率预测、比较与优化 |
| 组合构建 | 模型组合、基金筛选、自动组合构建 |
| 投后追踪 | 月度/季度健诊报告、目标进度、配置偏移和再平衡提醒 |

账户诊断、目标规划和组合优化在材料中是相邻但不同的能力。

## 3. Morningstar X-Ray 的定位

材料将 X-Ray 描述为：快速洞察投资者账户结构，清晰展示资产配置与风险暴露，并辅助顾问与客户沟通。

四项核心价值：

1. 还原账户真实资产结构和风险来源；
2. 使用晨星数据形成专业、直观的展示；
3. 识别集中度、风格、行业暴露和费率等盲点；
4. 用可视化降低组合分析的理解门槛。

材料展示的产品链路为：

```text
1. 持仓数据归集
2. 基金 E 账户赋能
3. 账户风险匹配
4. 业绩与底层透视
5. 多终端灵活接入
```

前三项和“业绩与底层透视”构成数据分析过程；H5、PDF、API 等属于交付方式。

## 4. 持仓数据归集

材料展示三种持仓进入方式：

| 方式 | 内容 | 主要场景 |
| --- | --- | --- |
| 自主录入 | 输入基金代码/份额，上传 Excel 或截图，建立模拟组合 | 公开平台、投前模拟 |
| 基金 E 账户 | 客户授权后同步全市场公募基金持仓 | 跨平台全市场持仓归集 |
| 机构数据库直连 | 对接银行或券商已有客户持仓 | App、顾问工作台、投后服务 |

归集后支持：

- 查看整体账户；
- 按平台分别查看；
- 展示总金额、基金数量、净值更新日和持仓截止日；
- 对整体账户及不同平台分别进行风险评价。

## 5. 底层持仓穿透

晨星大类资产穿透以产品全部持仓为基础，自下而上计算账户的真实暴露。

材料展示的穿透维度包括：

- 大类资产；
- 国家和地区；
- 行业；
- 大盘/中盘/小盘；
- 价值/平衡/成长风格；
- 股票估值；
- 债券类型及风险特征；
- 前十大底层证券；
- 基金之间的历史相关性；
- 基金公司集中度。

材料表达的关键含义是：基金数量多不等于风险已经分散，多只基金可能仍暴露于相同地区、行业、风格或底层证券。

## 6. MPRS 组合风险评分

MPRS 全称为 Morningstar Portfolio Risk Score，即晨星投资组合风险评分。材料将其描述为简单、直观、可靠的前瞻性组合风险指标。

### 6.1 材料指出的传统方法局限

- 取组合中单只产品的最高风险，不能代表组合风险；
- 将产品风险按权重简单线性相加，会忽略资产相关性和分散效果；
- 产品层级风险无法充分表达地区、行业、资产类别和多因子暴露。

### 6.2 风险匹配

材料将以下两者比较：

```text
组合风险评分 MPRS
vs.
投资者风险舒适区
```

风险舒适区由风险测评问卷和个人风险画像支持。材料提及 10 题或 25 题风险问卷。

材料中的 `57-76` 只是演示账户的风险舒适区，不是通用阈值。

### 6.3 三类示例

| 示例 | 组合特征 | 结论 |
| --- | --- | --- |
| 单一国家和行业集中 | 中国股票基金，科技行业集中 | 风险远高于舒适区 |
| 地区和行业分散 | 引入全球股票，但仍是纯权益 | 风险略高于舒适区 |
| 跨资产分散 | 加入债券和较低波动资产 | 风险进入舒适区 |

示例说明组合风险同时受到资产结构、集中度、相关性和多维风险因子的影响。

## 7. X-Ray 诊断报告内容

| 诊断模块 | 材料展示的信息 |
| --- | --- |
| 综合概况 | MPRS、风险舒适区、风险匹配结论、大类资产、概括性结论 |
| 组合概况 | 基金清单、权重、市值、数据日期、比较基准、基金评级 |
| 业绩分析 | 组合与基准走势、多区间回报、单只基金表现和评级 |
| 地区分布 | 国家/地区权重、与基准比较、地区集中提示 |
| 股票风格 | 大中小盘、价值平衡成长、风格箱 |
| 股票估值 | 市盈率、市净率、市销率、市现率及基准对比 |
| 行业配置 | 周期性、敏感性、防御性行业及超配/低配 |
| 费用和开支 | 综合费率、显性/隐性费用、管理费、交易费等 |
| 前十大持仓 | 穿透后的底层证券、占比和集中度 |
| 产品相关性 | 基金历史收益相关性矩阵 |
| 债券持仓 | 利率债、信用债、可转债、资产支持证券、海外债等 |
| 基金公司 | 管理规模、账户资产占比、基金数量和管理人集中度 |

补充说明：

- 材料示例中的相关性使用基金近三年每周净值回报计算；
- 历史相关性反映过去共同波动，不代表未来相关性；
- 业绩部分强调组合与基准比较，而不是只展示绝对收益；
- PDF 深度诊断报告用于客户留存和顾问持续解读。

## 8. 晨星基金数据与方法

### 8.1 数据范围

材料列出的数据包括：

- 基金基础信息、经理、管理人、费率和投资限制；
- 股票和债券持仓；
- 大类资产、地区和行业穿透；
- 股票和债券风格箱；
- 债券到期收益率、久期和信用分析；
- 净值、分红、回报、规模和资金流；
- 招募说明书、基金合同、定期报告；
- 晨星评级、分类、风格箱和适当性风险等级。

材料声称其基金持仓历史数据超过 25 年，并展示持仓数据 T+1 更新能力。该内容属于产品材料中的能力说明。

### 8.2 特色数据与方法

| 能力 | 材料中的方法或用途 |
| --- | --- |
| 晨星分类 | 全球统一分类，基于基金长期真实风格动态检查调整 |
| 晨星评级 | 关注 3/5/10 年表现，以风险调整后收益进行同类比较 |
| 综合费率 | 计算显性和隐性费用，支持 FOF 双层费率穿透 |
| 投资者回报 | 结合净值和资金流，以 IRR 估算投资者整体回报 |
| 基金业绩归因 | 使用材料所称 BF 方法，将股票超额收益拆为行业配置和个股选择 |
| 基金经理标签 | 背景、策略、持仓风格、业绩特征、持有人结构等 |
| 基金公司评价 | 业绩、规模、资金流、产品线、管理团队和费率等 |
| 产品适当性 | 持仓、评级调整、波动、下跌、短期业绩、规模、流动性、封闭期、杠杆等风险 |

基金业绩归因在材料中是基金级能力，不能直接视为账户级业绩归因。

## 9. 相邻能力

### 9.1 组合优化

材料描述的输入和目标包括：

- 客户 KYC、风险偏好和投资期限；
- 目标资产配置和当前持仓；
- 优选产品池；
- 最小化跟踪误差；
- 平衡阿尔法、大类资产跟踪误差和特异性风险；
- 输出优化后的产品、权重及风险收益数据。

### 9.2 目标规划

材料描述的能力包括：

- 构建资产负债和现金流信息；
- 设置短期与长期目标；
- 结合客户风险画像；
- 使用财富预测引擎、资本市场假设和通胀参数；
- 模拟目标达成概率；
- 形成与期限相关的资产配置建议。

### 9.3 AI 应用

材料把自然语言交互列为 AI 的核心接入点，应用包括：

- 多源研究汇总和产品筛选；
- 个性化组合建议和月度评论；
- 解释相对基准业绩；
- 资产配置偏移后的再平衡提醒；
- 调取客户组合、执行工作流和即时生成图表。

材料没有披露 AI 是否参与风险评分或适当性判断。

## 10. 交付形态

材料展示的交付方式包括：

- H5；
- 手机、Pad 和网页嵌入；
- A4 PDF 报告；
- API；
- 银行或券商 App；
- 理财顾问工作台。

API 内容概括为持仓资产穿透、收益风险数据、行业和地区等分布数据。

## 11. 材料可以确认的主线

```text
账户是否完整
→ 实际持有什么
→ 底层资产和风险暴露是什么
→ 组合整体风险是多少
→ 是否匹配客户风险舒适区
→ 是否存在集中、偏科、重复、相关性或费率等盲点
→ 组合和基准的业绩如何
→ 形成可视化报告供顾问和客户持续沟通
```

## 12. 材料没有明确回答的问题

1. MPRS 的完整公式、因子和权重；
2. 风险测评得分到风险舒适区的映射规则；
3. 各诊断结论的阈值和严重程度；
4. 账户或底层持仓数据不足时的评分规则；
5. 不同持仓披露时点的对齐方法；
6. 产品相关性对组合风险分数的具体贡献；
7. 诊断报告中配置建议的生成机制；
8. 账户级收益归因的具体方法；
9. 诊断、策略和适当性审核的系统边界；
10. AI 在诊断判断中的权限范围。

以上内容需要正式方法论文档、接口协议、数据字典或业务确认后才能补充。

## 13. 材料边界

资料一声明，材料、数据和观点仅供内部交流参考，不构成投资意见或建议；投资者仍需结合投资目的、期限、经验、资产状况和风险承受能力判断产品适配性。
